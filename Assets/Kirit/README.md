# Kirit

This folder contains project-owned Kirit content.

- `Scenes/KiritPrototype.unity` is the working baseline scene.
- The Convai Lip Sync Sample remains preserved as a read-only reference.
- `Scripts`, `Vision`, `Data`, and `Prefabs` are reserved for the next milestones.

The current scene intentionally keeps the sample avatar and Convai wiring while
the Kirit Character ID is configured in the scene's `ConvaiCharacter` component.
